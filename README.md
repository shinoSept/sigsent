# SigSent

แอปมือถืออ่านนิทานด้วยเสียง สำหรับ**เด็กตาบอดและสายตาเลือนราง**
เน้นกลุ่มเด็กชาติพันธุ์ปกาเกอะญอในประเทศไทย โดยใช้นิทานเป็นสื่อช่วยเรียนภาษาไทย

ส่วนนี้คือ **frontend ทั้งหมด** ระบบ AI (OCR, แปลปกาเกอะญอ, สร้างเสียง) อยู่ฝั่ง backend

---

## เริ่มใช้งาน

```bash
npm install
```

```bash
npx expo start
```

สแกน QR ด้วยแอป **Expo Go** บนมือถือ — ควรทดสอบบนเครื่องจริง เพราะกล้อง ไมโครโฟน
และโปรแกรมอ่านหน้าจอ (TalkBack / VoiceOver) ทำงานไม่ครบบน emulator

ตอนนี้แอปใช้**ข้อมูลจำลอง** จึงเปิดใช้ได้ครบทุกฟีเจอร์โดยไม่ต้องมีเซิร์ฟเวอร์

---

## ต่อกับ backend จริง

แก้ไฟล์ `.env` แล้วรีสตาร์ท ไม่ต้องแก้โค้ดหน้าจอเลย

```
EXPO_PUBLIC_USE_MOCK=0
EXPO_PUBLIC_API_URL=https://your-backend-url
```

สัญญา API ทั้งหมดอยู่ที่ [`src/services/api/types.ts`](src/services/api/types.ts)
ถ้า spec ของ backend ต่างจากนี้ ให้แก้เฉพาะ [`src/services/api/real/index.ts`](src/services/api/real/index.ts)
ไฟล์เดียว หน้าจอทุกหน้าไม่ต้องแตะ

| เมธอด | ใช้ตอน |
|---|---|
| `ingestPhotos` / `ingestFile` / `ingestText` | เพิ่มนิทานเข้าคลัง คืน `jobId` |
| `getJob` | ถามสถานะระหว่างประมวลผล |
| `listTales` / `getTale` / `deleteTale` | คลังนิทาน |
| `getNarration` | ขอไฟล์เสียงอ่านของทั้งเรื่อง |
| `chat` | ถามตอบเกี่ยวกับนิทาน |
| `transcribe` | แปลงเสียงพูดของเด็กเป็นข้อความ |

## หลักการออกแบบที่ต้องรักษาไว้

ผู้ใช้หลักมองไม่เห็นหรือเห็นเลือนราง สิ่งเหล่านี้จึงไม่ใช่ของตกแต่ง แต่เป็นเงื่อนไขที่ทำให้แอปใช้ได้จริง

1. **ทุกปุ่มต้องใช้ `A11yPressable`** ห้ามใช้ `TouchableOpacity` ดิบ
   คอมโพเนนต์นี้บังคับให้มี `accessibilityLabel` ครบ พื้นที่กดไม่ต่ำกว่า 64dp และสั่นตอบรับทุกครั้ง
2. **ทุกข้อความต้องใช้ `<Text>` ของโปรเจกต์** (`src/components/Text.tsx`)
   เพื่อให้ขยายตามขนาดที่ผู้ใช้เลือก และเลือกฟอนต์ตามอักษรของข้อความเอง
3. **ห้ามใส่โค้ดสีตรง ๆ** ให้ดึงจาก `useTheme()` เท่านั้น
   ทุกคู่สีผ่านการตรวจ WCAG แล้ว ถ้าเพิ่มสีใหม่ต้องเพิ่มการตรวจใน `scripts/check-contrast.ts` ด้วย
4. **ทุกอย่างที่เปลี่ยนสถานะต้องมีเสียงบอก** ใช้ `announce()` เช่น เปลี่ยนหน้านิทาน สุ่มได้เรื่องอะไร
   ถ่ายรูปไปกี่หน้าแล้ว เพราะผู้ใช้ไม่มีทางรู้จากการมองจอ
5. **รูปภาพและกราฟิกให้ปิดจาก screen reader** (`accessibilityElementsHidden`)
   ยกเว้นข้อมูลที่มีความหมายจริง เช่น ป้าย "ภาพประกอบสร้างโดย AI" ที่ต้องบอกผู้ใช้ตามหลักความโปร่งใส

## คำสั่งตรวจสอบ

```bash
npm run typecheck && npm run check:contrast && npm run check:fonts
```

- `check:contrast` ตรวจว่าทุกคู่สีในทั้งสองธีมผ่าน WCAG AA (ข้อความ 4.5:1, ไอคอนและขอบ 3:1)
- `check:fonts` ตรวจว่าเลือกฟอนต์ตามอักษรได้ถูก และตัดข้อความปนไทย-ปกาเกอะญอได้ครบ

## เรื่องภาษาปกาเกอะญอ

- คำแปลอยู่ที่ [`src/i18n/ksw.ts`](src/i18n/ksw.ts) ตอนนี้**ยังว่าง** รอเจ้าของภาษาเติม
  คีย์ไหนยังไม่มีคำแปลจะถอยไปใช้ภาษาไทยอัตโนมัติ จึงเติมทีละคีย์ได้เลย ไม่ต้องแปลครบก่อน
- ใช้ฟอนต์ **Padauk** ของ SIL ไม่ใช่ Noto Sans Myanmar เพราะ Noto วางสระและวรรณยุกต์
  ของภาษากะเหรี่ยงผิดตำแหน่ง (เช่น U+1037 ควรอยู่ซ้ายของ U+1061 แต่ Noto วางขวา)
- ข้อความที่ปนทั้งไทยและอักษรพม่าในประโยคเดียว ระบบจะตัดเป็นช่วงแล้วใส่ฟอนต์ให้แต่ละช่วงเอง
  (`splitByScript` ใน `src/theme/fontForText.ts`)

### สิ่งที่ยังต้องยืนยันกับเจ้าของภาษา

- [ ] ชุมชนเป้าหมายเขียนปกาเกอะญอด้วย **อักษรพม่า** หรือ **อักษรไทย** — ในไทยมีทั้งสองแบบ
      ถ้าใช้อักษรไทย ให้เปลี่ยน `fonts.ksw` ใน `src/theme/tokens.ts` เป็น Noto Sans Thai
- [ ] ชื่อภาษาที่แสดงในหน้าตั้งค่า ตอนนี้ใช้คำทับศัพท์ `Pgaz K'Nyau` ไว้ก่อน (`src/i18n/langs.ts`)

## เรื่องเสียงอ่าน

`useNarrator` รองรับสองแหล่งเสียงหลังหน้ากากเดียวกัน และ**เลือกให้เองอัตโนมัติ**

- **ไฟล์เสียงจาก backend** — ทางหลัก และเป็นทางเดียวที่อ่านปกาเกอะญอได้
- **เสียงสังเคราะห์ในเครื่อง** — ใช้เมื่อยังไม่มี `audioUrl` ทำให้แอปสาธิตและใช้งานได้เสมอ
  แม้เซิร์ฟเวอร์ยังไม่พร้อมหรือล่ม

หน้าจอคุยกับ `useNarrator` เท่านั้น วันที่ backend ส่ง `audioUrl` มาจริง ระบบจะสลับไปเล่นไฟล์เอง
โดยไม่ต้องแก้โค้ดหน้าจอแม้แต่บรรทัดเดียว

**ที่ยังต้องถามเพื่อน:** ไฟล์เสียงที่ส่งกลับมามี *timing marks* ระดับคำหรือประโยคไหม
ถ้ามี การไฮไลต์คำตามเสียงจะแม่นยำ ถ้าไม่มีระบบจะประมาณจากความยาวเสียงไปก่อน
(ดู `NarrationMark` ใน `src/services/api/types.ts`)

## โครงสร้าง

```
app/                    หน้าจอทั้งหมด (expo-router)
  (tabs)/               หน้าแรก / คลังนิทาน / พูดคุย / ตั้งค่า
  add/                  เพิ่มนิทาน: กล้อง พิมพ์ และหน้ารอประมวลผล
  tale/[id]/            ฟังนิทาน และคุยเกี่ยวกับนิทานเรื่องนั้น
src/
  audio/                useNarrator (เล่นนิทาน) และ useSpeaker (พูดคำตอบสั้น ๆ)
  components/           คอมโพเนนต์ที่ใช้ร่วมกัน เริ่มจาก A11yPressable และ Text
  i18n/                 ระบบภาษา th.ts เป็นต้นฉบับ ksw.ts รอเติม
  services/api/         สัญญา API พร้อม mock และ real
  store/                สถานะที่เก็บลงเครื่อง (การตั้งค่า และคลังนิทาน)
  theme/                สี ขนาด ฟอนต์ และตัวตรวจคอนทราสต์
```

## ทดสอบก่อนส่งประกวด

1. **เดินทุกขั้นตอนโดยไม่มองจอ** เปิด TalkBack (Android) หรือ VoiceOver (iOS)
   แล้วทำให้ครบ: เพิ่มนิทาน → เปิดฟัง → ถามคำถาม
   ทุกปุ่มต้องอ่านออกเสียงได้ว่าเป็นอะไรและกดแล้วจะเกิดอะไร
2. ตั้งขนาดตัวอักษรเป็น **ใหญ่ที่สุด** พร้อมเปิด **คอนทราสต์สูง** แล้วตรวจว่าไม่มีข้อความล้นหรือถูกตัด
3. สลับเป็นภาษาปกาเกอะญอ แล้วตรวจว่าอักษรแสดงถูกต้อง ไม่เป็นกล่องสี่เหลี่ยม ทั้ง Android และ iOS
4. ปิดเสียงเครื่อง (โหมดเงียบ) แล้วกดเล่น — ต้องยังได้ยินเสียงอ่าน
